# EPIC ROLL, rejestracja uczestników

Prototyp strony, na której uczestnik wpisuje numer zamówienia, imię i pierwszą literę nazwiska, a dostaje numer ID zapisany w arkuszu Google.

- [SPEC.md](SPEC.md): wymagania, przepływ, struktura arkusza, kontrakt API, testy akceptacyjne
- [TECH.md](TECH.md): stos (React + TypeScript, Tailwind, Google Apps Script, clasp, GitHub Pages), struktura repozytorium, wdrażanie
